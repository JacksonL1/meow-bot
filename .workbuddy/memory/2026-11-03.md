## 2026-11-04 上午：修「运行 exe 后拖不动、也没交互」

**现象**：用户反馈拖拽/点击/双击/右键全无反应，但画面正常（眼睛还追光标）。

**根因**：启动时 `set_ignore_cursor_events(true)`，指望页面收到 mousemove 命中 `#pet` 后再关掉穿透。
Electron 在 Windows 上有低级鼠标钩子转发 mousemove（`forward:true`）；Tauri（tao 0.37.2）
只设 `WS_EX_TRANSPARENT | WS_EX_LAYERED`（`platform_impl/windows/window_state.rs`），
页面一条 mousemove 都收不到 → 自我死锁 → 整窗永久穿透。

**修法**（S10-10）：
- 渲染层每 200ms 上报猫矩形 `hit_rects`（分身时每只 `.cat` 一个，不合并）
- 宿主每 60ms 读 `GetCursorPos` 比对矩形，翻转 `set_ignore_cursor_events`
- **拖动中强制不穿透**（否则窗口追光标慢半拍的那一拍吃掉 pointerup，dragging 卡死）
- 诊断：`window.clawd.hitState()` → ignore / inside / local / gazeTicks / gazePushes

**关键教训**：CDP 的 `Input.dispatchMouseEvent` 绕过 OS 命中测试，合成事件全绿也证明不了
"鼠标进得来"。闸门 75 → 80，并加了 SKIP 机制（环境调不动光标时响亮跳过，不冒充 PASS）。

**已验证**：注入覆盖光标的矩形 → ignore=false；离开 → ignore=true；真实光标在窗口外时 ignore=true。
**未验证**：真实鼠标拖拽那一下 —— 本会话环境禁止调用系统光标 API（Add-Type 被安全护栏拦），
挪不动光标，只能人工试。
