## 这一轮真正学到的东西

1. **`dsh headless` 建的会话，投影里没有 `turnOutline` / `modelSelection` / `sessionStats`**。
   前者靠我们自己从 stdout 接（`SayNote`），中者靠 `--dump-config` 的 `agent-default-model`
   补（必须标「默认」），后者只退回 `turnBoundary.lastTurn`。
2. **新窗口不会自己获得权限**。Tauri 的 ACL 是白名单：没登记进 capabilities 的窗口一条
   core 权限都没有，`plugin:event|listen` 直接被拒，而表现像"emit 丢了一帧"。我当时加了
   500ms 轮询兜底，把 bug 盖住了整整一轮。**兜底能救功能，救不了诊断。**
3. **同一个值被"展示"和"执行"两处分别算，一定会分叉**（目录在窗里写 Think、消息落进
   DeepseekWorkSpace）。只算一次、钉在状态里。
4. **验收脚本自己会撒谎**：`JSON.stringify(null)` 返回字符串 `"null"`（truthy），
   `if (!done)` 从此不再轮询，已通的链路显示成没通。
5. **能不能续是数据决定的**：`assertAdoptable` 拒收带 `agentPreset` 的会话。不绕，
   改成提前显示「桌面端会话 · 写不进去」。
