- **权限气泡「点了允许没有任何返回」修好**，commit `b2b1369`。真实时序（CDP 复刻）：
  卡片亮、按钮亮、点下去一个字节没发出去，请求挂满 **120000ms** 才回落 204。
  - 三条静默死路：① 卡片加载即可见 + 按钮初始可点，`currentId === null` 时静默 return；
    ② `decide()` 先清 state 再 fire-and-forget，`false` 没人接 → 窗永久冻住；
    ③ **我修 ①② 时自己引入的竞态**：`await` 回执后无条件 `currentId = null`，
    擦掉刚渲染上来的下一条请求 → 卡片显示 Read 却"没有当前请求"。
  - 规矩：**写异步回执后的状态前先比对身份** `if (currentId !== id) return;`；
    用户可点的入口必须能回答"发给谁了 / 对方收没收到"（`call` 而不是 `send`）；
    回执说"没有这条"就收窗（新命令 `bubble_close`，只给气泡窗、不产生裁决）。
  - 闸门：cargo test 68/68、verify:tauri **128/0**（新增 5 条，含"超时后点允许"复刻）。
